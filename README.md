# Briefly URL Shortener

A simple, fast, and scalable URL shortener service built with FastAPI and SQLAlchemy.

## Features
- Shorten any valid URL.
- Option to provide a custom alias for the link.
- Auto-generated Base62 short codes for URLs without custom aliases.
- Expiration dates support for short links.
- Fast and automatic redirection to the original URL.

## Getting Started

### Prerequisites
- Python 3.8+ 
- PostgreSQL (or simply use the provided Docker Compose file)

### Installation

1. **Create a virtual environment:**
```bash
python -m venv venv
```

2. **Activate the virtual environment:**
- Windows (`cmd`): `venv\Scripts\activate.bat`
- Windows (`PowerShell`): `.\venv\Scripts\Activate.ps1`
- macOS/Linux: `source venv/bin/activate`

3. **Install dependencies:**
```bash
pip install -r requirements.txt
```

4. **Set up the Database:**
If you have Docker installed, you can simply run:
```bash
docker-compose up -d
```
*Alternatively, configure your `DATABASE_URL` in a `.env` file or export it as an environment variable to point to your local database.*

### Running the Application
Start the FastAPI server natively using Uvicorn:
```bash
uvicorn app.main:app --reload
```
The API will be available at [http://localhost:8000](http://localhost:8000). 
You can explore the interactive OpenAPI documentation automatically generated by FastAPI at [http://localhost:8000/docs](http://localhost:8000/docs).

### Running Tests
The project uses `pytest` for automated testing. You can run the test suite to verify everything with:
```bash
pytest
```
